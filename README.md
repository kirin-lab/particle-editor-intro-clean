# Particle Editor

**繁體中文** | [English](README.en.md)

用瀏覽器快速建立、預覽並輸出適用於 **Spine 3.8.99** 的烘焙式粒子動畫。

不需要安裝套件，也不需要登入。圖片、參數與輸出內容都在使用者的瀏覽器中處理。

此 GitHub Repository 是 Particle Editor 的**工具介紹與問題回報頁面**，不包含編輯器程式碼。

## 這個工具能做什麼？

Particle Editor 可建立粒子效果，並輸出可匯入 Spine 的動畫。你可以調整粒子的移動、大小、旋轉、顏色與透明度，再透過預覽確認效果。

主要功能：

- 介面提供中文／English 一鍵切換，語言偏好只保存在瀏覽器本機
- 即時粒子預覽
- 固定隨機結果的烘焙預覽
- 循環動畫預覽
- 點、方向、圓形、圓環、方形與方環發射器
- 每組發射器可設定獨立 X／Y 座標，預覽與 Spine 輸出保持一致
- 可複製目前發射器的參數、曲線與圖片，快速製作變色或差分效果
- 方向發射器可設定發射總角度、發射口寬度與平均初始點
- 圓形、圓環、方形與方環的發射範圍寬高最高可設為 10000 px
- 向外、向內及環形中心線內外分流
- 平均散佈初始發射點
- 隨機種子：其他設定相同時，使用相同 seed 可重現效果；更換 seed 可嘗試不同分布
- 發射完成時間、粒子生命時間與隨機變動
- 每個發射器最多 300 顆粒子；高數量會增加輸出檔案大小與預覽負擔
- 獨立的「移動 Motion」區塊，可切換「飛行距離」與「初始速度（物理）」
- 發射密度、速度、大小及透明度曲線
- 每顆粒子可依「基礎大小 ± 隨機值」取得固定的隨機尺寸
- 可新增、拖曳與刪除節點的顏色時間軸
- 原圖顏色與 Multiply 漸層模式
- 垂直重力、360° 風向與風力強度、旋轉速度及方向對齊
- 背景圖片預覽、座標設定及選擇性匯出
- 50%／60%／70% 循環 cut
- 可設定循環動畫的目標總影格
- ZIP 一鍵輸出

## 建議工作流程

1. 新增、複製或選擇發射器；需要分開配置時，可在 ID／命名區設定各組 X／Y 座標。
2. 調整形狀、發射、移動控制、物理、旋轉及視覺參數。
3. 使用「即時預覽」確認大致效果。
4. 點「產生烘焙」，建立可預覽與輸出的固定版本。
5. 使用「烘焙預覽」確認即將輸出的固定版本。
6. 如需循環動畫，選擇 50%、60% 或 70% 循環 cut，再點「製作循環」。
7. 使用「循環預覽」確認 `_repeat` 動畫。
8. 如需固定總長度，在「目標循環」輸入總影格並建立、預覽目標動畫。
9. 輸入檔名並點「輸出烘焙」。

修改參數後，舊烘焙結果不會自動改變。請點「更新烘焙」產生新的固定版本。

## 介面與移動模式

左側是發射器與參數設定區，右側是預覽畫面。上方第一排包含預覽、背景、視角、載入與輸出；第二排集中烘焙與循環流程。背景與視角使用浮動面板，不會壓縮預覽高度。

每個發射器可在 **ID／命名** 設定獨立 X／Y 座標，並在 **移動 Motion** 選擇：

- **飛行距離（舊模式）**：設定生命週期內的總移動距離；生命時間增加時，平均速度會降低。舊設定檔預設使用此模式。
- **初始速度（物理）**：直接設定發射瞬間的 `px/s`；增加生命時間不會降低設定的初始速度；可搭配重力與風力調整效果。

載入舊設定檔後，請先確認發射器位置與移動效果，再重新烘焙。

## 循環 cut

製作循環後，工具會保留原動畫，並新增：

```text
原動畫名稱_repeat
```

例如原動畫名稱為 `particle01`，循環動畫會命名為 `particle01_repeat`。

循環 cut 可選：

- **50%**：更短的循環，需留意粒子重疊與軌跡檢查結果
- **60%**：循環較短、節奏較密集
- **70%**：預設值，建議先以此比例預覽

請透過循環預覽比較不同 cut 比例，確認粒子銜接與整體節奏。

切換 50%／60%／70% 後，請重新點「製作循環」，避免預覽與輸出使用不同的比例。

### 目標循環總長度

製作 `_repeat` 後，在「目標循環」輸入需要的總影格，再建立並預覽目標動畫。調整總長度可能改變播放節奏，請確認效果後再輸出。

若出現警告或無法建立，請依介面提示調整目標影格或粒子設定，再重新製作循環。輸出後仍建議在 Spine 檢查循環交界。

## 輸出內容

點「輸出烘焙」會下載 ZIP。檔名會附加辨識資訊，方便區分多次輸出。以下以 `particles` 為例，示意壓縮檔內的內容：

```text
particles.zip
├─ particles.json
├─ particles_notforspine.json
└─ images/
   ├─ 1_par_01.png
   ├─ 2_par_01.png
   └─ background.png
```

- `particles.json`：匯入 Spine 的正式動畫資料
- `particles_notforspine.json`：重新載入 Particle Editor 的設定檔，請勿匯入 Spine
- `images/`：每個發射器各自的粒子圖片，以及選擇匯出時的背景圖片

重新載入設定檔後，請確認循環 cut 比例與目標總影格，再重新製作循環。

## 匯入 Spine

1. 解壓縮輸出的 ZIP。
2. 在 Spine 選擇 **File → Import Data**。
3. 選擇 `particles.json`。
4. 將圖片路徑指向解壓縮後的 `images/`。
5. 原動畫會使用發射器名稱；如果製作過循環，Animations 中也會出現 `_repeat` 動畫。

本工具不會產生 `.atlas`，如工作流程需要 Atlas，請在 Spine 或其他 Atlas 工具中另外建立。

## 自訂圖片與背景

Visual 的「素材原始朝向」可選右、上、左、下；「角度微調」用來補償素材本身的傾斜。需要讓圖片跟隨移動方向時，可搭配 Rotation 的「對齊方向」，並在預覽中確認朝向。

- 每個發射器使用獨立檔名，例如 `1_par_01.png`、`2_par_01.png`，不會互相覆蓋。
- 烘焙後更換圖片時，新圖片會同步套用到烘焙預覽、循環預覽與輸出，不會改變既有的粒子移動效果。
- 自訂粒子圖片會保留原始寬高比例與像素尺寸；最長邊超過 2048 px 時才會等比例縮小。
- 「基礎大小」控制粒子的顯示尺寸，以圖片最長邊為基準，並保持原始寬高比例。
- 「大小隨機 ±」可增加粒子的尺寸變化；例如基礎大小 5、隨機 ±2，起始尺寸範圍為 3～7 px。大小曲線可調整後續的大小變化。
- 建議自訂圖片小於 **2 MB**。
- 建議最長邊不超過 **2048 px**。
- 較小的粒子圖片通常能獲得更穩定的預覽與較小的輸出檔案。
- 背景圖片只用於預覽；勾選「匯出背景」後才會寫入 ZIP。
- 背景會保持原始寬高比例，不會強制轉成正方形。
- 「適合背景」只調整預覽視角，不影響輸出內容。
- 匯出的背景會保留設定的位置，並顯示在粒子後方。
- 重新載入 `_notforspine.json` 時會還原背景座標，但仍需重新選擇背景圖片。

## 預覽模式

- **即時預覽**：快速調整最新參數，隨機細節可能變化
- **烘焙預覽**：播放上一次固定的烘焙結果
- **循環預覽**：檢查已製作的 `_repeat` 循環效果

「重播」只會從頭播放目前結果，不會重新抽樣。若要產生不同的固定結果，請使用「重新抽樣烘焙」。

## 相容性與限制

- 目標格式：Spine 3.8.99
- 建議瀏覽器：最新版 Chrome 或 Edge
- 最多 10 個發射器
- 每個發射器最多 300 顆粒子
- 粒子數量越多，預覽與輸出動畫的效能負擔越高，請依專案需求控制數量
- 瀏覽器預覽與 Spine 中的效果可能有細微差異，請以匯入後的實際效果為準
- 烘焙及循環結果只存在目前的網頁工作階段；重新載入設定檔後需再次烘焙
- 工具沒有自動存檔，關閉頁面前請先輸出 ZIP
- 介面語言只影響顯示文字，不會改變輸出檔案與動畫名稱
